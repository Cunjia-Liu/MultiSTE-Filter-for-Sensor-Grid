## Recording future contributions

Keep the existing Git history and make new commits with clear descriptions of
the changes. GitHub's automatic contributor listing uses commit attribution;
this document records credits that commit history alone may not capture.

For a genuinely jointly authored change, add a `Co-authored-by` trailer using
each contributor's chosen GitHub-associated or GitHub no-reply email address.
Do not add someone as a co-author of a new commit solely because they authored
the original software. AI assistance can be noted in a commit message or here;
no AI account or invented author email is needed.

See [GitHub's co-author documentation](https://docs.github.com/en/pull-requests/how-tos/commit-changes/creating-a-commit-with-multiple-authors).
